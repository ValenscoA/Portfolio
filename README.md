# Valensco Aurelius portfolio

A personal portfolio built with Next.js App Router, TypeScript, Motion, Lenis,
and CSS Modules.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Production

```bash
npm run build
npm start
```

The project uses the standard Next.js build pipeline and can be deployed to
Vercel without a custom build command.
